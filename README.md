# ГРА-склад Сборка — десктоп-приложение (Windows 10/11)

Kiosk-обёртка на Electron поверх веб-приложения сборки заказов. Приложение открывается на весь экран и даёт сайту прямой доступ к железу рабочего места сборщика.

## Что это

Рабочее место на складе: сотрудник входит по отпечатку пальца, собирает заказы в веб-интерфейсе, а приложение печатает этикетки напрямую на термопринтер без системного диалога печати.

## Возможности

- Прямая печать этикеток на термопринтер Xprinter XP-365B (58×40 мм, 203 dpi): PDF/PNG рендерится в 1-битный битмап и отправляется RAW-командами TSPL в очередь печати через winspool.WritePrinter — без диалога драйвера.
- Вход по отпечатку пальца: сканер R558-S подключён к ESP32, обмен по USB-serial. Сотрудник прикладывает палец и попадает в своё рабочее место.
- Регистрация отпечатков (enroll) и идентификация из админки.
- Таймаут сессии: после простоя экран блокируется, требуется повторный вход. Тот же сотрудник возвращается на прежнее место, другой — в свой кабинет.
- Админка с логином/паролем: настройки, управление отпечатками, проверка и установка обновлений.
- Опциональная вторая очередь печати для маленьких этикеток «Честного знака» (20×20 мм).

## Структура

- `src/main.js` — главный процесс: kiosk-окно, IPC, обновления.
- `src/preload.js` — мост оболочки (`window.desktopBridge`).
- `src/printer.js` — печать PDF/PNG → битмап → TSPL RAW, установка драйвера.
- `src/fingerprint.js` — serial-клиент ESP32 (enroll / identify / load).
- `src/dispenser.js` — управление дозатором по serial.
- `src/config.js` — конфиг в userData (siteUrl, порты, принтер, таймаут).
- `assets/shell.{html,css,js}` — оболочка: экран отпечатка, админка, host webview.
- `assets/webview-preload.js` — мост сайта внутри webview.
- `firmware/` — прошивки ESP32 (протокол отпечатка и дозатора).
- `printer-driver/` — драйвер принтера и скрипты установки.

## Горячие клавиши

- `Ctrl+Shift+Alt+Q` — выход из kiosk.
- `Ctrl+Shift+Alt+D` — DevTools.

## Разработка

```
npm install
npm run rebuild   # пересобрать serialport под текущий Electron
npm start
```

## Сборка установщика

```
npm run dist      # -> release/GRA-sklad-Setup-<version>.exe (NSIS, electron-builder)
```

## Конфигурация

Скопируйте `config.example.json` в `%APPDATA%/grasklad-desktop/config.json` и задайте свои значения.
`siteUrl` — адрес веб-приложения сборки, `desktopSecret` должен совпадать с секретом на сервере
(переменная окружения `DESKTOP_SECRET`). Значения можно менять и через раздел «Настройки» в админке.

## Требования

- Windows 10/11 x64, Node.js 18+, Electron 32.
- Термопринтер Xprinter XP-365B (лента 58×40 мм).
- ESP32 + сканер отпечатка R558-S (UART 57600 8N2 между сканером и ESP32).

Двоичные пакеты Xprinter/Seagull и CH340 в репозиторий не включены. Для установки принтера и USB-драйвера положите собственный пакет производителя в printer-driver/ перед сборкой установщика; скрипты установки сохранены.
